# 有据 · 75 秒演示脚本

录制：1080p 屏幕录制，60–90 秒，导出 MP4（< 500MB），保存在 `docs/`，不要放进 `public/`。

0–8s：黑底白字，“传统的答案之书，给你一句模棱两可的话。” 翻到“有据”：“这本给你出处。”
8–20s：输入“房东不退押金怎么办？”，点“翻一签”。
20–35s：签卡落下：签文、三行账、证据 A、第 15 节的对应条目。
35–55s：点“展开这本账”：3–7 条行动、别做清单、书里没写的、该找谁。
55–65s：点“存成签卡”，展示分享图。
65–75s：切到 Agent API 页面，展示 `ask_life_question` 的请求/响应；“它也可以被别的智能体调用。”
